Cette version nécessite Node.js et permet des fonctionnalités
avancées (API, base de données, SSR, etc.)


┌───────────────────────────────────────────────────────────────┐
│  PRÉREQUIS                                                     │
└───────────────────────────────────────────────────────────────┘

   ⚠️  Vous devez avoir installé :

   • Node.js (version 18 ou supérieure)
     → Télécharger : https://nodejs.org/

   • npm (inclus avec Node.js)
     → Vérifier : npm --version


┌───────────────────────────────────────────────────────────────┐
│  ÉTAPE 1 : INSTALLER LES DÉPENDANCES                         │
└───────────────────────────────────────────────────────────────┘

   Ouvrez un terminal dans le dossier racine du projet et tapez :

   npm install

   ⏳ Cela va installer toutes les dépendances nécessaires
      (Next.js, React, Tailwind CSS, TypeScript, etc.)

   ⌛ Temps estimé : 1-3 minutes selon votre connexion


┌───────────────────────────────────────────────────────────────┐
│  ÉTAPE 2 : LANCER LE SITE EN MODE DÉVELOPPEMENT              │
└───────────────────────────────────────────────────────────────┘

   Dans le même terminal, tapez :

   npm run dev

   ✅ Le site va démarrer sur : http://localhost:3000

   🔄 Le rechargement automatique est activé :
      toute modification du code recharge la page automatiquement


┌───────────────────────────────────────────────────────────────┐
│  ÉTAPE 3 : OUVRIR DANS VOTRE NAVIGATEUR                      │
└───────────────────────────────────────────────────────────────┘

   Ouvrez votre navigateur et allez sur :

   👉 http://localhost:3000

   Le site est maintenant accessible ! 🎉


┌───────────────────────────────────────────────────────────────┐
│  COMMANDES UTILES                                             │
└───────────────────────────────────────────────────────────────┘

   npm run dev      → Lancer en mode développement
   npm run build    → Construire pour la production
   npm start        → Lancer en mode production
   npm run lint     → Vérifier le code

┌───────────────────────────────────────────────────────────────┐
│  DÉPLOIEMENT EN PRODUCTION                                    │
└───────────────────────────────────────────────────────────────┘

   Option 1 - Vercel (recommandé)
   ────────────────────────────────
   1. Créer un compte sur vercel.com
   2. Connecter votre repo GitHub
   3. Vercel détecte automatiquement Next.js
   4. Cliquer sur "Deploy"
   → Site en ligne en 2 minutes !

   Option 2 - Build manuel
   ────────────────────────
   1. npm run build
   2. Le dossier /out contient les fichiers statiques
   3. Upload sur votre serveur web

   Option 3 - Netlify
   ────────────────────
   1. Connecter votre repo
   2. Build command: npm run build
   3. Publish directory: out
   4. Deploy !


┌───────────────────────────────────────────────────────────────┐
│  RÉSOLUTION DE PROBLÈMES                                      │
└───────────────────────────────────────────────────────────────┘

   ❌ "npm: command not found"
   → Installez Node.js depuis nodejs.org

   ❌ "Port 3000 is already in use"
   → Un autre processus utilise le port 3000
   → Solution : Tuez le processus ou utilisez un autre port :
     PORT=3001 npm run dev

   ❌ Erreurs de compilation TypeScript
   → Vérifiez la syntaxe dans les fichiers .tsx
   → Les erreurs sont affichées dans le terminal

   ❌ "Module not found"
   → Supprimez node_modules/ et package-lock.json
   → Relancez : npm install
